# 🛒 Blinkit Sales Dashboard using Power BI

## 📌 Project Overview
This project presents an interactive Power BI dashboard built to analyze Blinkit's retail sales data. The dashboard provides insights into sales performance, customer preferences, and outlet distribution to support data-driven decision-making.

---

## 🎯 Objective
The main objective of this project is to:
- Analyze sales performance across different outlet types and locations
- Identify top-performing products and categories
- Understand customer behavior and preferences
- Track key business KPIs for better decision-making

---

## 📊 Dashboard Features
- 💰 Total Sales Analysis
- 📦 Number of Items Sold
- ⭐ Average Rating
- 📈 Year-wise Sales Trends
- 🏪 Outlet Type & Location Analysis
- 🥗 Fat Content Distribution (Low Fat vs Regular)
- 📊 Item Type Performance

---

## 🔍 Key Insights
- Tier-based outlet performance comparison
- Identification of top-selling product categories
- Sales contribution by outlet size and type
- Customer rating trends across products
